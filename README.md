# Susu & Neko 夢幻森林旅店

以遊戲形式溫習默書嘅網站（香港粵語讀音），適合 iPad 及手機使用。

## 默書範圍
- （一）第八課詞語：尋找、旅遊、建築、藍色、設施、北京、踮起、地圖、河流、認識、中國、一幅
- （二）第十二課全課《森林旅店（上）》

## 七個遊戲房間
| 房間 | 遊戲 | 玩法 |
|---|---|---|
| 101 | 星星泡泡 | 聽讀音，篤穿寫啱嘅泡泡 |
| 102 | 翻翻魔法卡 | 詞語同意思配成一對 |
| 103 | 魔法聽寫・詞語 | 聽讀音，喺田字格寫出嚟 |
| 201 | 魔法補字 | 句子唔見咗詞語，補返佢 |
| 202 | 小兔執房間 | 將句子排返啱嘅次序 |
| 203 | 標點糖果屋 | 揀啱標點放入格 |
| 204 | 模擬默書 | 逐句聽、逐句寫（讀埋標點） |

## 備註
- 讀音由 Microsoft 香港粵語女聲（HiuGaai／HiuMaan）合成，部分字音（例如「着」、「簿」、「踮」）建議家長聽一聽再確認。
- 星星記錄只存喺當次瀏覽，重新載入會清零。
- 純靜態網站（HTML／CSS／JavaScript），無需安裝。
